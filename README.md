## 🚀 Featured Projects

### Database Systems
| Project | Description |
|---|---|
| **QUANT-DB** | Research prototype that makes shape-based pattern search over financial time-series a native SQL operation, combining domain-adapted compression, a hardware-aware execution kernel, and a cost-based optimizer that reasons jointly over vector similarity and relational predicates. |
| **Morphing Pages** | Page-level, temperature-driven encoding engine for columnar storage. Pages migrate across HOT/WARM/COLD states through a copy-on-write protocol, validated under concurrent load and ThreadSanitizer with zero torn-page reads across tens of millions of accesses. |
| **Morphing Vectors** | Recency-tiered approximate nearest-neighbor index built on a from-scratch hierarchical graph and product quantizer. Vectors move to coarser quantization tiers as they age, with formal recall-decay and migration-cost analysis, benchmarked against FAISS HNSW. |
| **Autonomous Database Optimization System** | Self-adaptive database architecture that tunes internal configuration based on workload behavior. |
| **FinanceDB** | Modular time-series database architecture with adaptive storage efficiency and flexible query processing. |
| **QueryForge** | Relational database engine written from scratch in Python, with no external dependencies, ORMs, or third-party SQL libraries. |
| **LiteDB** | Low-level storage engine demonstrating manual mapping of C++ structures to a binary on-disk format. |
| **Time-Series Buffer Manager** | Tiered-temporal buffer manager in Rust for line-speed ingestion that protects hot (recent) data from eviction by large historical scans. |
